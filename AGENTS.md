# Project instructions

Before planning, implementing, or reviewing changes, read and follow
[ARCHITECTURE.md](ARCHITECTURE.md). It defines the project's purpose,
boundaries, and required design principles.

After completing a task that changes functionality, run
`make build && make lint && make test` as the final verification step, after all
edits and before reporting completion. Fix any failures and rerun the full
sequence after further edits; all three commands must pass.
